# Beauty Shelf Easy

✅ Prompt detalhado para usar , TEM QUE AGIR COMO um desenvolvedor senior m faz uso de todos os ferramentas necessarias para atingir meu ojetivo.

Quero que você crie uma loja virtual (e-commerce) completa e simples de usar, voltada para venda de produtos cosméticos, incluindo marcas como Natura e O Boticário.

🎯 Objetivo

Criar uma plataforma moderna, intuitiva e responsiva (desktop e mobile), onde clientes possam visualizar produtos, comprar facilmente e realizar pagamentos online com segurança.

🛍️ Funcionalidades principais

1. Catálogo de produtos

Exibir produtos com:

Nome

Imagem

Descrição

Preço

Organização por categorias (ex: perfumes, kits, cremes, etc.)

Permitir destacar produtos (ex: “mais vendidos” ou “promoção”)

2. Cadastro e gestão de produtos (MUITO IMPORTANTE)

Quero um sistema simples para eu mesmo gerenciar os produtos, sem precisar programar:

Criar um painel administrativo (admin dashboard) acessível por login

No painel, permitir:

Adicionar novos produtos

Editar produtos existentes

Excluir produtos

Campos obrigatórios no cadastro:

Nome do produto

Preço

Descrição

Upload de imagem

Categoria

Opção de marcar como “frete grátis”

Permitir criação de kits (combinação de produtos)

3. Página de produto

Mostrar detalhes completos do produto

Botão claro de “Comprar”

Indicação se tem frete grátis

4. Carrinho de compras

Adicionar/remover produtos

Mostrar total da compra

Atualizar quantidade

5. Checkout e pagamento

Integração com Stripe

Redirecionamento seguro para pagamento

Após pagamento:

Exibir confirmação de compra

Mostrar resumo do pedido

6. Fluxo do usuário

Usuário acessa o site

Navega pelos produtos

Seleciona um produto ou kit

Adiciona ao carrinho

Finaliza compra

Faz pagamento via Stripe

Recebe confirmação

7. Design e experiência

Layout moderno e limpo

Fácil navegação

Mobile-first (funcionar bem no celular)

Botões claros e intuitivos

⚙️ Tecnologias (flexível)

Pode usar ferramentas modernas (React, etc.)

Backend simples e funcional

Banco de dados para armazenar produtos e pedidos

🚀 Extras importantes (se possível)

Sistema de login simples para admin

Estrutura pronta para escalar depois

Código organizado e fácil de manter

🔑 Prioridade principal

O mais importante é:
👉 Eu conseguir cadastrar, editar e gerenciar produtos facilmente sem conhecimento técnico.

💡 Dica estratégica (importante pra você)

Mesmo usando E garantir que VOCE:

Use algo tipo CMS interno ou painel visual

Ou integre com algo como Supabase / Firebase
